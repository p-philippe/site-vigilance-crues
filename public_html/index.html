Indice SWI mensuel catnat — Météo-France Open Data
Soil Wetness Index uniforme sur 50 ans, maille 8 km. Utilisé pour les dossiers catastrophes naturelles (sécheresse/inondation).
 📖
Définition SWI — Eaufrance glossaire
SWI ≈ 1 : sol humide/saturé · SWI → 0 : stress hydrique. Modèle SIM (Safran-Isba-Modcou), résolution 8 km, pas de temps quotidien.
Données de calcul : Open-Meteo ERA5-Land / ECMWF — humidité volumétrique par couche · Référence sols INRAE/BDAT (limon-argile Bretagne) · θwp=0,10 · θfc=0,28 · θsat=0,44 m³/m³

Nappes phréatiques — Côtes-d'Armor (22) — Chaque piézomètre est comparé à sa propre chronique historique pour le même mois (percentile, approche BRGM) : une nappe au 90ᵉ centile est exceptionnellement haute pour la saison, quelle que soit sa profondeur absolue. Nappe très haute = bassin sans capacité d'absorption, crues amplifiées et risque de remontée de nappe. Source : Hub'Eau API v1 niveaux nappes.
